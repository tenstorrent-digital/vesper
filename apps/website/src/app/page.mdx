## A quick look

Import the styles once at the root of your app, then import each component from its own entrypoint:

```tsx
import "@tenstorrent/vesper/styles.css";

import { Button } from "@tenstorrent/vesper/button";
import { ArrowRight } from "@tenstorrent/vesper/icons";

export const GetStarted = () => (
  <Button as="a" href="/getting-started" iconRight={<ArrowRight />}>
    Get started
  </Button>
);
```

That code renders this button:

<Button as={Link} href="/getting-started" iconRight={<ArrowRight />}>
  Get started
</Button>

Every component has its own entrypoint, so your bundler only ships the ones you actually use. See [Getting Started](/getting-started) for the full setup, including usage in Tailwind apps, and font loading.

## What's inside

- **40+ components:** buttons, inputs, menus, modals, toasts, and the rest of the surfaces product UIs are built from.
- **125+ icons:** tree-shakeable SVG components, plus an `Icon` component for rendering them by name.
- **Design tokens:** color, spacing, radius, shadow, and type exposed as CSS variables you can build your own UI with.
- **Light and dark themes:** color tokens resolve per theme, so components adapt without extra work.
- **Tailwind v4 support:** one extra import turns the token set into Tailwind utilities like `bg-vesper-purple-300`.
- **Accessible by default:** components are tested against WCAG 2 AA in both themes as part of the test suite.

## Theming

Vesper ships light and dark themes out of the box. Tokens resolve to the values for the active theme. A component looks right in either one without a second set of styles, and so does anything you build with the same tokens.

Read more in [Tokens](/tokens), which lists every CSS variable alongside its light and dark values.
