# Show More

A toggle button that switches between "Show more" and "Show less" labels with a caret icon. Used to expand and collapse content sections. [View in Storybook]({`${STORYBOOK_URL}/show-more`})

<ShowMore />

## Options

| Prop       | Type                                   | Description                                                                               | Default |
| ---------- | -------------------------------------- | ----------------------------------------------------------------------------------------- | ------- |
| `expanded` | `boolean`                              | Whether the content is currently expanded. Controls the button label and `aria-expanded`. | `false` |
| `disabled` | `boolean`                              | When `true`, renders the button in a disabled state and prevents interaction.             | `false` |
| `onClick`  | `MouseEventHandler<HTMLButtonElement>` | Callback fired when the show more/less button is clicked.                                 | —       |

## Examples

```tsx
import { ShowMore } from "@repo/vesper/show-more";

// Basic uncontrolled toggle
const [expanded, setExpanded] = useState(false);

<div>
  {expanded && <p>Additional content revealed here.</p>}
  <ShowMore expanded={expanded} onClick={() => setExpanded(!expanded)} />
</div>;
```

```tsx
// Disabled state
<ShowMore disabled />
```
