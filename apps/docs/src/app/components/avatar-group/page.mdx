# Avatar Group

Displays a stacked row of avatars with an overflow indicator when more than three are provided. Useful for showing team members, collaborators, or participants at a glance. [View in Storybook]({`${STORYBOOK_URL}/avatar-group`})

<AvatarGroup
  size="md"
  avatars={[
    { src: "https://i.pravatar.cc/128?u=1", alt: "User 1" },
    { src: "https://i.pravatar.cc/128?u=2", alt: "User 2" },
    { src: "https://i.pravatar.cc/128?u=3", alt: "User 3" },
    { src: "https://i.pravatar.cc/128?u=4", alt: "User 4" },
  ]}
/>

## Options

| Prop      | Type                                           | Description                                                                                                | Default |
| --------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------- |
| `size`    | `"sm" \| "md" \| "lg"`                         | The size applied to all avatars in the group.                                                              | `"md"`  |
| `avatars` | `{ src: string \| undefined; alt?: string }[]` | The list of avatars to display. A maximum of 3 are shown, with an overflow indicator for additional items. | —       |
| `as`      | `ElementType`                                  | The root element type for polymorphic rendering.                                                           | `"div"` |

## Examples

```tsx
import { AvatarGroup } from "@tenstorrent/vesper/avatar-group";

// Basic usage
<AvatarGroup
  avatars={[
    { src: "/user1.png", alt: "Alice" },
    { src: "/user2.png", alt: "Bob" },
  ]}
/>;
```

```tsx
// With overflow indicator (more than 3 avatars)
<AvatarGroup
  size="lg"
  avatars={[
    { src: "/user1.png", alt: "Alice" },
    { src: "/user2.png", alt: "Bob" },
    { src: "/user3.png", alt: "Carol" },
    { src: "/user4.png", alt: "Dave" },
    { src: "/user5.png", alt: "Eve" },
  ]}
/>
```
