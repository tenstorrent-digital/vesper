# Textarea

A multi-line text input component supporting optional labels and validation messages. Built on the native `<textarea>` element for full form compatibility.

<Textarea label="Bio" placeholder="Tell us about yourself" />

## Options

| Prop          | Type                                             | Description                                                                                        | Default     |
| ------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------- | ----------- |
| `size`        | `"sm" \| "md" \| "lg"`                           | The size of the textarea. Affects padding and typography.                                          | `"md"`      |
| `variant`     | `"default" \| "warning" \| "success" \| "error"` | The visual variant, which determines color scheme and message icon.                                | `"default"` |
| `label`       | `string`                                         | An optional label displayed above the textarea. An asterisk is appended when `required` is `true`. | —           |
| `message`     | `string`                                         | An optional message displayed below the textarea, paired with a variant-specific icon.             | —           |
| `height`      | `number`                                         | The fixed height of the textarea in pixels, scaling with base rem size.                            | `104`       |
| `textareaRef` | `Ref<HTMLTextAreaElement>`                       | A ref forwarded to the underlying `<textarea>` element.                                            | —           |
| `placeholder` | `string`                                         | Placeholder text for the textarea.                                                                 | `" "`       |
| `maxLength`   | `number`                                         | The maximum number of characters the user can enter.                                               | —           |
| `minLength`   | `number`                                         | The minimum number of characters required for the field to be valid.                               | —           |
| `disabled`    | `boolean`                                        | When `true`, prevents interaction.                                                                 | `false`     |
| `required`    | `boolean`                                        | When `true`, marks the textarea as required.                                                       | `false`     |
| `readOnly`    | `boolean`                                        | When `true`, makes the textarea read-only.                                                         | `false`     |

Any other props are forwarded either to the underlying `<textarea>` element or to the wrapping `<div>`, depending on the prop.

Unlike [the `TextInput` component](./text-input.mdx), `Textarea` does not support icons or a `type` prop, since neither of them apply to multi-line text.

## Examples

### Uncontrolled vs controlled

The simplest way to use the `Textarea` component is to render it in an uncontrolled fashion, where the component is responsible for keeping track of its own value:

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea placeholder="Enter some text" />;
```

If you need to control the value of the `Textarea`, you can do so via the `value` and `onChange` props:

```tsx
import { useState } from "react"
import { Textarea } from "@tenstorrent/vesper/textarea"

const [value, setValue] = useState("")

<Textarea
  placeholder="Enter some text"
  value={value}
  onChange={e => setValue(e.target.value)}
/>
```

### Different sizes

The `Textarea` component can be rendered at `sm`, `md`, or `lg` size, defaulting to `md`. Size affects the padding and text styles of the textarea.

<Textarea size="sm" placeholder="A small textarea" />
<Textarea size="md" placeholder="A medium textarea" />
<Textarea size="lg" placeholder="A large textarea" />

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea"

<Textarea size="sm" placeholder="A small textarea" />
<Textarea size="md" placeholder="A medium textarea" />
<Textarea size="lg" placeholder="A large textarea" />
```

### Setting the height

The `Textarea` component is not resizable by the user. Instead, you can set a fixed height in pixels via the `height` prop, which defaults to `104`. The value is converted to `rem`, so the rendered height scales with the base font size.

<Textarea
  label="Release notes"
  placeholder="Summarise what changed in this release"
  height={200}
/>

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea
  label="Release notes"
  placeholder="Summarise what changed in this release"
  height={200}
/>;
```

### Disabling the textarea

You can disable a textarea by passing `disabled={true}` or just `disabled` as a prop:

<Textarea
  label="Overview"
  placeholder="Add a brief outline of your project"
  disabled
/>

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea
  label="Overview"
  placeholder="Add a brief outline of your project"
  disabled
/>;
```

### Message

You can render an additional line of text under the input element via the `message` prop. Combine with the `variant` prop to indicate the tone of the message to the user.

<Textarea
  label="Bio"
  placeholder="Tell us about yourself"
  message="This will be displayed on your public profile."
/>

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea
  label="Bio"
  placeholder="Tell us about yourself"
  message="This will be displayed on your public profile."
/>;
```

### Variants

The `Textarea` component can be rendered in one of four variants: `default`, `warning`, `success`, or `error`. The variant determines the colour scheme of the textarea, as well as the icon paired with its `message`.

#### Default variant

A `Textarea` renders with the `default` variant when no `variant` prop is specified. Its `message` is best suited for neutral hints, such as formatting requirements:

<Textarea
  label="Bio"
  placeholder="Tell us about yourself"
  message="Markdown is supported, up to 500 characters."
  maxLength={500}
/>

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea
  label="Bio"
  placeholder="Tell us about yourself"
  message="Markdown is supported, up to 500 characters."
  maxLength={500}
/>;
```

#### Warning variant

Use the `warning` variant to flag a value that needs attention, but that doesn't prevent the form from being submitted:

<Textarea
  variant="warning"
  label="Commit message"
  defaultValue="fix stuff"
  message="This commit message is quite short."
/>

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea
  variant="warning"
  label="Commit message"
  value={commitMessage}
  onChange={(e) => setCommitMessage(e.target.value)}
  message="This commit message is quite short."
/>;
```

#### Success variant

The `success` variant is best suited for confirming that a value has been validated as expected:

<Textarea
  variant="success"
  label="SSH public key"
  defaultValue="ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIL4rT9m2 you@example.com"
  message="This key is valid and ready to be added."
/>

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea
  variant="success"
  label="SSH public key"
  value={publicKey}
  onChange={(e) => setPublicKey(e.target.value)}
  message="This key is valid and ready to be added."
/>;
```

#### Error variant

The `error` variant highlights an invalid value that must be corrected before the form can be submitted:

<Textarea
  variant="error"
  label="Feedback"
  defaultValue="No"
  message="Please provide at least 20 characters of feedback."
  minLength={20}
  required
/>

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea
  variant="error"
  label="Feedback"
  value={feedback}
  onChange={(e) => setFeedback(e.target.value)}
  message="Please provide at least 20 characters of feedback."
  minLength={20}
  required
/>;
```

### Labels and required fields

When a `label` is provided, it is rendered above the textarea and associated with it, so clicking the label focuses the field. Passing `required` appends an asterisk to the label:

<Textarea label="Feedback" placeholder="What could we do better?" required />

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea label="Feedback" placeholder="What could we do better?" required />;
```

If you render a required `Textarea` without a `label`, the asterisk is appended to the `placeholder` instead:

<Textarea placeholder="What could we do better?" required />

```tsx
import { Textarea } from "@tenstorrent/vesper/textarea";

<Textarea placeholder="What could we do better?" required />;
```

An `id` is generated for you, but you can provide your own if you need to reference the field elsewhere. Any `aria-describedby` you pass is merged with the automatically generated `message` id, so both remain announced by assistive technology.

### Usage in forms

`Textarea` renders a native `<textarea>`, so it works with regular form submission and native validation via props like `name`, `form`, `required`, `minLength`, and `maxLength`:

```tsx
import { Button } from "@tenstorrent/vesper/button";
import { Textarea } from "@tenstorrent/vesper/textarea";

<form action="/api/feedback" method="post">
  <Textarea
    name="feedback"
    label="Feedback"
    placeholder="What could we do better?"
    minLength={20}
    maxLength={500}
    required
  />
  <Button type="submit">Submit</Button>
</form>;
```

### Accessing the underlying element

Use the `textareaRef` prop when you need direct access to the underlying `<textarea>` element, eg. to focus it or read its selection:

```tsx
import { useRef } from "react"
import { Textarea } from "@tenstorrent/vesper/textarea"

const textareaRef = useRef<HTMLTextAreaElement>(null)

<Textarea
  label="Bio"
  placeholder="Tell us about yourself"
  textareaRef={textareaRef}
/>
```
