# Tabs

A set of components for organizing content into switchable panels. Supports primary and secondary visual styles, icons in tab triggers, and controlled or uncontrolled selection.

```tsx demo
import {
  TabPanel,
  TabsList,
  TabsRoot,
  TabTrigger,
} from "@tenstorrent/vesper/tabs";
import { Typography } from "@tenstorrent/vesper/typography";

export default function TabsDemo() {
  return (
    <TabsRoot defaultValue="overview">
      <TabsList>
        <TabTrigger value="overview" label="Overview" />
        <TabTrigger value="settings" label="Settings" />
        <TabTrigger value="activity" label="Activity" />
      </TabsList>
      <TabPanel value="overview">
        <Typography>Overview content.</Typography>
      </TabPanel>
      <TabPanel value="settings">
        <Typography>Settings content.</Typography>
      </TabPanel>
      <TabPanel value="activity">
        <Typography>Activity content.</Typography>
      </TabPanel>
    </TabsRoot>
  );
}
```

## Anatomy

Tabs are built by composing four components:

- `TabsRoot` groups the other parts together, and keeps track of which tab is selected.
- `TabsList` contains the tab triggers.
- `TabTrigger` is a button that selects a tab.
- `TabPanel` contains the content that is shown while its tab is selected.

```tsx
<TabsRoot>
  <TabsList>
    <TabTrigger />
  </TabsList>
  <TabPanel />
</TabsRoot>
```

`TabsList` and `TabPanel` must be rendered within a `TabsRoot`, and `TabTrigger` must be rendered within a `TabsList`. Rendering any of them outside of their parent throws an error.

## Options

### `TabsRoot` options

| Prop | Type | Description | Default |
| --- | --- | --- | --- |
| `variant` | `"primary" \| "secondary"` | The visual style variant of the tabs. | `"primary"` |
| `value` | `string` | The value of the selected tab (controlled mode). | — |
| `defaultValue` | `string` | The value of the tab to select by default (uncontrolled mode). | — |
| `onValueChange` | `(value: string) => void` | Callback fired when a new tab is selected. | — |
| `activationMode` | `"automatic" \| "manual"` | Whether a tab is selected when its trigger receives focus (`automatic`) or only once its trigger is clicked (`manual`). | `"automatic"` |
| `children` | `ReactNode` | A `TabsList`, and the `TabPanel`s its triggers select. | — |

`TabsRoot` forwards any other props to the underlying `<div>` element.

### `TabsList` options

| Prop | Type | Description | Default |
| --- | --- | --- | --- |
| `children` | `ReactNode` | The `TabTrigger`s to render, in the order they are displayed. | — |

`TabsList` forwards any other props to the underlying `<div>` element, which has the `tablist` role.

### `TabTrigger` options

| Prop | Type | Description | Default |
| --- | --- | --- | --- |
| `value` | `string` | The value of the tab this trigger selects. Must be unique within its `TabsRoot`. **Required.** | — |
| `label` | `string` | The text label displayed in the trigger. **Required.** | — |
| `icon` | `ReactNode` | An optional icon element rendered before the label. | — |

`TabTrigger` doesn't accept `children`: use `label` and `icon` to set its content instead. It forwards any other props to the underlying `<button>` element, which has the `tab` role.

### `TabPanel` options

| Prop | Type | Description | Default |
| --- | --- | --- | --- |
| `value` | `string` | The value of the tab this panel belongs to. The panel is shown while the `TabTrigger` with the same `value` is selected. **Required.** | — |
| `keepMounted` | `boolean` | When `true`, keeps the panel in the DOM while it is hidden. | `false` |
| `children` | `ReactNode` | The content of the panel. | — |

`TabPanel` forwards any other props to the underlying `<div>` element, which has the `tabpanel` role.

## Examples

### Pairing triggers with panels

Each `TabTrigger` is associated with the `TabPanel` that shares its `value`. Triggers are displayed in the order they are rendered within `TabsList`, and each trigger is linked to its panel for assistive technology via `aria-controls` and `aria-labelledby`:

```tsx demo
import {
  TabPanel,
  TabsList,
  TabsRoot,
  TabTrigger,
} from "@tenstorrent/vesper/tabs";
import { Typography } from "@tenstorrent/vesper/typography";

export default function BasicTabs() {
  return (
    <TabsRoot defaultValue="details">
      <TabsList>
        <TabTrigger value="details" label="Details" />
        <TabTrigger value="history" label="History" />
      </TabsList>
      <TabPanel value="details">
        <Typography>Everything you need to know about this item.</Typography>
      </TabPanel>
      <TabPanel value="history">
        <Typography>A log of every change made to this item.</Typography>
      </TabPanel>
    </TabsRoot>
  );
}
```

### Variants

Tabs can be rendered in one of two variants, which you can set with the `variant` prop on `TabsRoot`. The default `primary` variant is meant for page-level navigation, while the more compact `secondary` variant suits switching between views inside a smaller container, such as a card or a panel:

```tsx demo
import {
  TabPanel,
  TabsList,
  TabsRoot,
  TabTrigger,
  type TabsVariant,
} from "@tenstorrent/vesper/tabs";
import { Typography } from "@tenstorrent/vesper/typography";

function ExampleTabs({ variant }: { variant: TabsVariant }) {
  return (
    <TabsRoot variant={variant} defaultValue="preview">
      <TabsList>
        <TabTrigger value="preview" label="Preview" />
        <TabTrigger value="code" label="Code" />
      </TabsList>
      <TabPanel value="preview">
        <Typography>The rendered output.</Typography>
      </TabPanel>
      <TabPanel value="code">
        <Typography>The source code.</Typography>
      </TabPanel>
    </TabsRoot>
  );
}

export default function TabsVariants() {
  return (
    <div
      style={{
        display: "flex",
        flexDirection: "column",
        gap: "var(--vesper-spacing-8)",
      }}
    >
      <ExampleTabs variant="primary" />
      <ExampleTabs variant="secondary" />
    </div>
  );
}
```

### Rendering icons

Pass an icon as a `ReactNode` to a `TabTrigger`'s `icon` prop to render it before the trigger's label:

```tsx demo
import { Gear, Globe } from "@tenstorrent/vesper/icons";
import {
  TabPanel,
  TabsList,
  TabsRoot,
  TabTrigger,
} from "@tenstorrent/vesper/tabs";
import { Typography } from "@tenstorrent/vesper/typography";

export default function TabsWithIcons() {
  return (
    <TabsRoot defaultValue="general">
      <TabsList>
        <TabTrigger value="general" label="General" icon={<Globe />} />
        <TabTrigger value="advanced" label="Advanced" icon={<Gear />} />
      </TabsList>
      <TabPanel value="general">
        <Typography>General settings.</Typography>
      </TabPanel>
      <TabPanel value="advanced">
        <Typography>Advanced settings.</Typography>
      </TabPanel>
    </TabsRoot>
  );
}
```

### Laying out panels

You can render a `TabPanel` anywhere within its `TabsRoot`, not only as a direct child. In this example, a [`Material`](./material.mdx) surface wraps both panels, and each panel is styled through its own `style` prop, which `TabPanel` passes to the `<div>` it renders:

```tsx demo
import { Material } from "@tenstorrent/vesper/material";
import {
  TabPanel,
  TabsList,
  TabsRoot,
  TabTrigger,
} from "@tenstorrent/vesper/tabs";
import { Typography } from "@tenstorrent/vesper/typography";

const PANEL_STYLE = { padding: "var(--vesper-spacing-4)" };

export default function TabsPanelLayout() {
  return (
    <TabsRoot defaultValue="summary">
      <TabsList>
        <TabTrigger value="summary" label="Summary" />
        <TabTrigger value="configuration" label="Configuration" />
      </TabsList>
      <Material style={{ marginTop: "var(--vesper-spacing-4)" }}>
        <TabPanel value="summary" style={PANEL_STYLE}>
          <Typography>A high-level overview of this deployment.</Typography>
        </TabPanel>
        <TabPanel value="configuration" style={PANEL_STYLE}>
          <Typography>
            The settings this deployment was created with.
          </Typography>
        </TabPanel>
      </Material>
    </TabsRoot>
  );
}
```

### Keeping panels mounted

By default, a `TabPanel` is removed from the DOM while its tab isn't selected, so any state inside it (such as text typed into a field, or its scroll position) is lost when the user switches tabs. Pass `keepMounted` to a `TabPanel` to hide it without removing it instead:

```tsx demo
import {
  TabPanel,
  TabsList,
  TabsRoot,
  TabTrigger,
} from "@tenstorrent/vesper/tabs";
import { TextArea } from "@tenstorrent/vesper/text-area";
import { Typography } from "@tenstorrent/vesper/typography";

export default function KeepMountedTabs() {
  return (
    <TabsRoot defaultValue="notes">
      <TabsList>
        <TabTrigger value="notes" label="Notes" />
        <TabTrigger value="help" label="Help" />
      </TabsList>
      <TabPanel value="notes" keepMounted>
        <TextArea
          aria-label="Notes"
          placeholder="Type something, then switch tabs and come back"
        />
      </TabPanel>
      <TabPanel value="help">
        <Typography>Anything typed into the notes field is kept.</Typography>
      </TabPanel>
    </TabsRoot>
  );
}
```

### Uncontrolled vs controlled

Render `TabsRoot` in an uncontrolled fashion to let it keep track of its own selection, passing `defaultValue` to choose which tab is active initially. If you omit `defaultValue`, the first tab is selected initially.

If you need to control which tab is selected, pass `value` alongside `onValueChange`:

```tsx demo
import { useState } from "react";

import {
  TabPanel,
  TabsList,
  TabsRoot,
  TabTrigger,
} from "@tenstorrent/vesper/tabs";
import { Typography } from "@tenstorrent/vesper/typography";

export default function ControlledTabs() {
  const [tab, setTab] = useState("first");

  return (
    <TabsRoot value={tab} onValueChange={setTab}>
      <TabsList>
        <TabTrigger value="first" label="First" />
        <TabTrigger value="second" label="Second" />
      </TabsList>
      <TabPanel value="first">
        <Typography>First panel.</Typography>
      </TabPanel>
      <TabPanel value="second">
        <Typography>Second panel.</Typography>
      </TabPanel>
    </TabsRoot>
  );
}
```

### Activation mode

By default, moving focus between tab triggers with the arrow keys activates each tab as it receives focus. Pass `activationMode="manual"` to `TabsRoot` to require `Enter`, `Space`, or a click before the panel changes, which is the better choice when a panel's content is expensive to render or fetch:

```tsx demo
import {
  TabPanel,
  TabsList,
  TabsRoot,
  TabTrigger,
} from "@tenstorrent/vesper/tabs";
import { Typography } from "@tenstorrent/vesper/typography";

export default function ManualTabs() {
  return (
    <TabsRoot activationMode="manual" defaultValue="metrics">
      <TabsList>
        <TabTrigger value="metrics" label="Metrics" />
        <TabTrigger value="logs" label="Logs" />
      </TabsList>
      <TabPanel value="metrics">
        <Typography>
          Focus the tabs and use the arrow keys: the panel only changes once you
          press Enter or Space.
        </Typography>
      </TabPanel>
      <TabPanel value="logs">
        <Typography>Logs panel.</Typography>
      </TabPanel>
    </TabsRoot>
  );
}
```
