# Snippet

A compact code display component with a built-in copy-to-clipboard button. Ideal for displaying short commands, installation instructions, or single-line code snippets.

<Snippet>yarn add @tenstorrent/vesper</Snippet>

## Options

| Prop       | Type                      | Description                                                                                               | Default     |
| ---------- | ------------------------- | --------------------------------------------------------------------------------------------------------- | ----------- |
| `children` | `string`                  | The code text to display. Also used as the value copied to the clipboard when the copy button is clicked. | —           |
| `variant`  | `"default" \| "contrast"` | The visual style variant of the snippet.                                                                  | `"default"` |

Any additional props are forwarded to the underlying `<div>` element.

## Examples

### Basic usage

Render a `Snippet` by wrapping string children with it:

<Snippet>yarn add @tenstorrent/vesper</Snippet>

```tsx
import { Snippet } from "@tenstorrent/vesper/snippet";

<Snippet>yarn add @tenstorrent/vesper</Snippet>;
```

### Variants

A `Snippet` can be rendered in one of two variants: `"default"` or `"contrast"`. The default variant is `"default"`. Use the `"contrast"` variant to render a `Snippet` using a color palette that contrasts with the current theme:

<Snippet variant="default">curl https://api.example.com/data</Snippet>
<Snippet variant="contrast">curl https://api.example.com/data</Snippet>

```tsx
import { Snippet } from "@tenstorrent/vesper/snippet";

<Snippet variant="default">curl https://api.example.com/data</Snippet>
<Snippet variant="contrast">curl https://api.example.com/data</Snippet>
```

### Multiline snippets

`Snippet` preserves newlines in the content it renders, so you can also pass string children with line breaks if you want to render multiline snippets:

<Snippet>
  nvm use 24
  node -v >> .nvmrc
</Snippet>

```tsx
import { Snippet } from "@tenstorrent/vesper/snippet";

<Snippet>{"nvm use 24 node\nnode -v >> .nvmrc"}</Snippet>;
```
