# Sheet

A slide-in panel that appears from the left or right edge of the viewport. Can operate as a modal dialog with a backdrop or as a popover that allows interaction with content behind it. Renders a title and description in its header, and any children you pass (including action buttons and forms) in its body. You can control its open state with the `open` and `onOpenChange` props, or leave the sheet to manage it.

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Sheet } from "@tenstorrent/vesper/sheet";

export default function SheetDemo() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open sheet</Button>
      <Sheet
        open={isOpen}
        onOpenChange={setIsOpen}
        title="Sheet panel"
        description="This is a slide-in panel."
      >
        Sheet content goes here.
      </Sheet>
    </>
  );
}
```

## Options

| Prop | Type | Description | Default |
| --- | --- | --- | --- |
| `title` | `string` | The title text displayed in the sheet header. Used for `aria-labelledby`. **Required.** | — |
| `description` | `string` | A description displayed below the title. Used for `aria-describedby`. **Required.** | — |
| `side` | `"left" \| "right"` | The side of the viewport the sheet slides in from. | `"right"` |
| `popover` | `boolean` | When `true`, renders as a popover without a backdrop, allowing interaction behind it. | `false` |
| `open` | `boolean` | Whether the sheet is open (controlled mode). Leave this out to let the sheet manage its own open state. | — |
| `defaultOpen` | `boolean` | Whether the sheet is open when it first renders (uncontrolled mode). | `false` |
| `onOpenChange` | `(open: boolean) => void` | Called with the new open state whenever it changes, such as when the user dismisses the sheet. In controlled mode, update the state you pass to `open` in response. | — |
| `children` | `ReactNode` | The content displayed inside the sheet body, such as text, action buttons, or a form. | — |

All other props, including `ref`, are forwarded to the underlying `<dialog>` element.

Use a `Sheet` for supplementary content alongside the current view, such as filters, settings, or the details of a selected row. When the content demands the user's full attention before they can carry on, reach for [the `Modal` component](./modal.mdx) instead.

## Examples

### Opening and closing a sheet

Pass `open` to control a `Sheet`. Setting it to `true` opens the sheet, and setting it back to `false` closes it. Keep that value in your own state, and pass its setter to `onOpenChange` so the sheet closes when the user dismisses it:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Sheet } from "@tenstorrent/vesper/sheet";

export default function BasicSheet() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open settings</Button>
      <Sheet
        open={isOpen}
        onOpenChange={setIsOpen}
        title="Settings"
        description="Manage your preferences."
      >
        Sheet content goes here.
      </Sheet>
    </>
  );
}
```

When the user presses `Escape`, clicks the close button in the header, or (in the default modal mode) clicks the backdrop behind it, the sheet calls `onOpenChange(false)`. Update your state in response, because the sheet doesn't close until `open` changes.

### Uncontrolled sheets

Leave out `open` to let a `Sheet` manage its own open state. An uncontrolled sheet closes itself when the user dismisses it. Pass `defaultOpen` to open it on its first render, or open the underlying `<dialog>` element through `ref`, by calling `showModal()` on it (or `showPopover()` in popover mode):

```tsx demo
import { useRef } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Sheet } from "@tenstorrent/vesper/sheet";

export default function UncontrolledSheet() {
  const ref = useRef<HTMLDialogElement>(null);

  return (
    <>
      <Button onClick={() => ref.current?.showModal()}>What's new?</Button>
      <Sheet
        ref={ref}
        title="What's new"
        description="A quick look at this release."
      >
        <div
          style={{
            display: "flex",
            flexDirection: "column",
            gap: "var(--vesper-spacing-6)",
            alignItems: "flex-start",
            minHeight: "100%",
          }}
        >
          Projects can now be shared with everyone in your workspace.
          <Button
            style={{ marginTop: "auto", marginLeft: "auto" }}
            onClick={() => ref.current?.close()}
          >
            Done
          </Button>
        </div>
      </Sheet>
    </>
  );
}
```

`onOpenChange` still fires whenever an uncontrolled sheet opens or closes. Use a controlled sheet when other parts of your UI depend on whether the sheet is open.

### Choosing a side

A sheet slides in from the right by default. Pass `side="left"` to have it slide in from the left instead, which tends to suit navigation:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Sheet } from "@tenstorrent/vesper/sheet";

export default function LeftSheet() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open navigation</Button>
      <Sheet
        open={isOpen}
        onOpenChange={setIsOpen}
        side="left"
        title="Navigation"
        description="Browse sections."
      >
        Sheet content goes here.
      </Sheet>
    </>
  );
}
```

### Popover mode

By default a `Sheet` behaves like a modal dialog: it renders a backdrop, traps focus, and blocks interaction with the rest of the page. Passing `popover` renders it as a popover instead, with no backdrop, so the user can keep working with the content behind it:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Sheet } from "@tenstorrent/vesper/sheet";

export default function PopoverSheet() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open details</Button>
      <Sheet
        open={isOpen}
        onOpenChange={setIsOpen}
        popover
        title="Details"
        description="Additional information."
      >
        This sheet does not block interaction with the page behind it, so you
        can keep scrolling and clicking while it is open.
      </Sheet>
    </>
  );
}
```

Use popover mode for panels the user consults while working, such as inspectors and help content, and stick with the default modal mode when the panel's task should be finished before anything else happens.
