# Sheet

A slide-in panel that appears from the left or right edge of the viewport. Can operate as a modal dialog with a backdrop or as a popover that allows interaction with content behind it. Renders a title and description in its header, and any children you pass (including action buttons and forms) in its body. You control whether it's open with the `open` and `onOpenChange` props.

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Sheet } from "@tenstorrent/vesper/sheet";

export default function SheetDemo() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open sheet</Button>
      <Sheet
        open={isOpen}
        onOpenChange={setIsOpen}
        title="Sheet panel"
        description="This is a slide-in panel."
      >
        Sheet content goes here.
      </Sheet>
    </>
  );
}
```

## Options

| Prop | Type | Description | Default |
| --- | --- | --- | --- |
| `title` | `NonNullable<ReactNode>` | The title displayed in the sheet header. Used for `aria-labelledby`. **Required.** | — |
| `description` | `NonNullable<ReactNode>` | A description displayed below the title. Used for `aria-describedby`. **Required.** | — |
| `side` | `"left" \| "right"` | The side of the viewport the sheet slides in from. | `"right"` |
| `popover` | `boolean` | When `true`, renders as a popover without a backdrop, allowing interaction behind it. | `false` |
| `open` | `boolean` | Whether the sheet is open. **Required.** | — |
| `onOpenChange` | `(open: boolean) => void` | Called with `false` when the sheet requests to close, such as when the user dismisses it. Update the state you pass to `open` in response. **Required.** | — |
| `children` | `ReactNode` | The content displayed inside the sheet body, such as text, action buttons, or a form. | — |

All other props, including `ref`, are forwarded to the underlying `<dialog>` element. The sheet only opens and closes when `open` changes, so don't call methods such as `showModal()` or `close()` on the `<dialog>` element through `ref`.

Use a `Sheet` for supplementary content alongside the current view, such as filters, settings, or the details of a selected row. When the content demands the user's full attention before they can carry on, reach for [the `Modal` component](./modal.mdx) instead.

## Examples

### Opening and closing a sheet

A `Sheet` opens when `open` is `true`, and closes when it's `false`. Keep that value in your own state, and pass its setter to `onOpenChange` so the sheet closes when the user dismisses it:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Sheet } from "@tenstorrent/vesper/sheet";

export default function BasicSheet() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open settings</Button>
      <Sheet
        open={isOpen}
        onOpenChange={setIsOpen}
        title="Settings"
        description="Manage your preferences."
      >
        Sheet content goes here.
      </Sheet>
    </>
  );
}
```

When the user presses `Escape`, clicks the close button in the header, or (in the default modal mode) clicks the backdrop behind it, the sheet calls `onOpenChange(false)`. Update your state in response, because the sheet doesn't close until `open` changes.

### Choosing a side

A sheet slides in from the right by default. Pass `side="left"` to have it slide in from the left instead, which tends to suit navigation:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Sheet } from "@tenstorrent/vesper/sheet";

export default function LeftSheet() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open navigation</Button>
      <Sheet
        open={isOpen}
        onOpenChange={setIsOpen}
        side="left"
        title="Navigation"
        description="Browse sections."
      >
        Sheet content goes here.
      </Sheet>
    </>
  );
}
```

### Popover mode

By default a `Sheet` behaves like a modal dialog: it renders a backdrop, traps focus, and blocks interaction with the rest of the page. Passing `popover` renders it as a popover instead, with no backdrop, so the user can keep working with the content behind it:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Sheet } from "@tenstorrent/vesper/sheet";

export default function PopoverSheet() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open details</Button>
      <Sheet
        open={isOpen}
        onOpenChange={setIsOpen}
        popover
        title="Details"
        description="Additional information."
      >
        This sheet does not block interaction with the page behind it, so you
        can keep scrolling and clicking while it is open.
      </Sheet>
    </>
  );
}
```

Use popover mode for panels the user consults while working, such as inspectors and help content, and stick with the default modal mode when the panel's task should be finished before anything else happens.
