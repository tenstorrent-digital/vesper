# Modal

A dialog overlay component for displaying focused content that requires user attention or interaction. Renders a title and description in its header, and any children you pass (including action buttons and forms) in its body. You can control its open state with the `open` and `onOpenChange` props, or leave the modal to manage it.

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Modal } from "@tenstorrent/vesper/modal";

export default function ModalDemo() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open modal</Button>
      <Modal
        open={isOpen}
        onOpenChange={setIsOpen}
        title="Confirm action"
        description="Are you sure you want to proceed?"
      >
        <div
          style={{
            display: "flex",
            flexDirection: "column",
            gap: "var(--vesper-spacing-6)",
          }}
        >
          Additional content can be placed here.
          <div
            style={{
              display: "flex",
              justifyContent: "flex-end",
              gap: "var(--vesper-spacing-4)",
            }}
          >
            <Button variant="tertiary" onClick={() => setIsOpen(false)}>
              Cancel
            </Button>
            <Button onClick={() => setIsOpen(false)}>Confirm</Button>
          </div>
        </div>
      </Modal>
    </>
  );
}
```

## Options

| Prop | Type | Description | Default |
| --- | --- | --- | --- |
| `title` | `string` | The title text displayed in the modal header. Used for `aria-labelledby`. **Required.** | — |
| `description` | `string` | A description displayed below the title. Used for `aria-describedby`. **Required.** | — |
| `width` | `number \| string` | The width of the modal container. A number is interpreted as pixels. | `452` |
| `open` | `boolean` | Whether the modal is open (controlled mode). Leave this out to let the modal manage its own open state. | — |
| `defaultOpen` | `boolean` | Whether the modal is open when it first renders (uncontrolled mode). | `false` |
| `onOpenChange` | `(open: boolean) => void` | Called with the new open state whenever it changes, such as when the user dismisses the modal. In controlled mode, update the state you pass to `open` in response. | — |
| `closeOnClickOutside` | `boolean` | When `true`, clicking the backdrop dismisses the modal. | `false` |
| `dismissible` | `boolean` | When `false`, the user can't dismiss the modal: `Escape` and backdrop clicks are ignored, and the header close button is disabled. Setting `open` to `false`, or calling `close()` through `ref`, still closes it. | `true` |
| `children` | `ReactNode` | The content displayed inside the modal body, such as text, action buttons, or a form. | — |

All other props, including `ref`, are forwarded to the underlying `<dialog>` element.

A `Modal` always blocks interaction with the rest of the page while it is open. When the user should be able to keep working with the content behind the panel, reach for [the `Sheet` component](./sheet.mdx) in `popover` mode instead.

## Examples

### Opening and closing a modal

Pass `open` to control a `Modal`. Setting it to `true` opens the modal, and setting it back to `false` closes it. Keep that value in your own state, and pass its setter to `onOpenChange` so the modal closes when the user dismisses it:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Modal } from "@tenstorrent/vesper/modal";

export default function BasicModal() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open modal</Button>
      <Modal
        open={isOpen}
        onOpenChange={setIsOpen}
        title="Welcome"
        description="Thanks for signing up."
      >
        You can start exploring features right away.
      </Modal>
    </>
  );
}
```

`Modal` renders a native `<dialog>`. While it's open, it traps focus and blocks interaction with the rest of the page. When the user presses `Escape` or clicks the close button in the header, the modal calls `onOpenChange(false)`. Update your state in response, because the modal doesn't close until `open` changes.

To stop users from being able to close a modal, (for example, if you're rendering a form inside a modal), see [Preventing dismissal](#preventing-dismissal).

### Uncontrolled modals

Leave out `open` to let a `Modal` manage its own open state. An uncontrolled modal closes itself when the user dismisses it. Pass `defaultOpen` to open it on its first render, or call `showModal()` on the underlying `<dialog>` element through `ref`:

```tsx demo
import { useRef } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Modal } from "@tenstorrent/vesper/modal";

export default function UncontrolledModal() {
  const ref = useRef<HTMLDialogElement>(null);

  return (
    <>
      <Button onClick={() => ref.current?.showModal()}>What's new?</Button>
      <Modal
        ref={ref}
        title="What's new"
        description="A quick look at this release."
      >
        <div
          style={{
            display: "flex",
            flexDirection: "column",
            gap: "var(--vesper-spacing-6)",
          }}
        >
          Projects can now be shared with everyone in your workspace.
          <div style={{ display: "flex", justifyContent: "flex-end" }}>
            <Button onClick={() => ref.current?.close()}>Done</Button>
          </div>
        </div>
      </Modal>
    </>
  );
}
```

`onOpenChange` still fires whenever an uncontrolled modal opens or closes. Use a controlled modal when other parts of your UI depend on whether the modal is open.

### Sizing

A modal is `452px` wide by default. Pass `width` to change that, either as a number (interpreted as pixels) or as any CSS length string.

The modal grows to fit its content. To keep long content from making it too tall, wrap that content in a scrollable element with a `maxHeight`:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Modal } from "@tenstorrent/vesper/modal";
import { Typography } from "@tenstorrent/vesper/typography";

const RELEASE_NOTES = [
  "Added a dark theme, which follows your system preference by default.",
  "Added keyboard shortcuts for the most common actions.",
  "Improved search performance across large projects.",
  "Improved the layout of settings pages on small screens.",
  "Fixed an issue where notifications were sometimes shown twice.",
  "Fixed an issue where exported files used the wrong time zone.",
];

export default function WideModal() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open wide modal</Button>
      <Modal
        open={isOpen}
        onOpenChange={setIsOpen}
        width={640}
        title="Release notes"
        description="Everything that changed in this release."
      >
        <div
          style={{
            display: "flex",
            flexDirection: "column",
            gap: "var(--vesper-spacing-6)",
          }}
        >
          <div
            role="region"
            aria-label="Release notes"
            tabIndex={0}
            style={{
              display: "flex",
              flexDirection: "column",
              gap: "var(--vesper-spacing-4)",
              maxHeight: "8rem",
              overflowY: "auto",
            }}
          >
            {RELEASE_NOTES.map((note) => (
              <Typography key={note}>{note}</Typography>
            ))}
          </div>
          <div style={{ display: "flex", justifyContent: "flex-end" }}>
            <Button onClick={() => setIsOpen(false)}>Close</Button>
          </div>
        </div>
      </Modal>
    </>
  );
}
```

### Closing on click outside

Clicking the backdrop does nothing by default, which keeps users from dismissing a modal by accident. Pass `closeOnClickOutside` to allow users to dismiss a modal by clicking the backdrop:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Modal } from "@tenstorrent/vesper/modal";

export default function DismissibleModal() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Open modal</Button>
      <Modal
        open={isOpen}
        onOpenChange={setIsOpen}
        closeOnClickOutside
        title="Keyboard shortcuts"
        description="Press Escape or click outside to dismiss."
      >
        This modal can be dismissed by clicking the backdrop behind it.
      </Modal>
    </>
  );
}
```

### Usage in forms

To use a modal as a form, render a `<form>` element as its children, with the form's fields and action buttons inside it. A button with `type="submit"` then submits the form natively, and native validation runs before the submit handler fires:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Modal } from "@tenstorrent/vesper/modal";
import { TextInput } from "@tenstorrent/vesper/text-input";
import { Typography } from "@tenstorrent/vesper/typography";

export default function FormModal() {
  const [isOpen, setIsOpen] = useState(false);
  const [submitted, setSubmitted] = useState<string | null>(null);

  return (
    <div
      style={{
        display: "flex",
        flexDirection: "column",
        gap: "var(--vesper-spacing-4)",
        alignItems: "flex-start",
      }}
    >
      <Button onClick={() => setIsOpen(true)}>Create project</Button>
      {submitted && (
        <Typography variant="copy-sm">Created project: {submitted}</Typography>
      )}
      <Modal
        open={isOpen}
        onOpenChange={setIsOpen}
        title="Create project"
        description="Enter the details for your new project."
      >
        <form
          style={{
            display: "flex",
            flexDirection: "column",
            gap: "var(--vesper-spacing-6)",
          }}
          onSubmit={(event) => {
            event.preventDefault();
            const data = new FormData(event.currentTarget);
            setSubmitted(String(data.get("name") ?? ""));
            setIsOpen(false);
          }}
        >
          <TextInput
            required
            aria-label="Project name"
            placeholder="Project name"
            name="name"
          />
          <div
            style={{
              display: "flex",
              justifyContent: "flex-end",
              gap: "var(--vesper-spacing-4)",
            }}
          >
            <Button
              variant="tertiary"
              type="button"
              onClick={() => setIsOpen(false)}
            >
              Cancel
            </Button>
            <Button type="submit">Create</Button>
          </div>
        </form>
      </Modal>
    </div>
  );
}
```

> [!NOTE]
>
> Buttons rendered inside a `form` default to `type="submit"`, so give any button that should not submit an explicit `type="button"`, as the cancel button above does.

### Preventing dismissal

Some flows shouldn't be interrupted, such as while a form is submitting a request. Set `dismissible` to `false` to stop users from closing the modal: pressing `Escape` and clicking the backdrop do nothing, and the close button in the header is disabled. Setting `open` to `false` still closes the modal, so you can close it yourself once the flow completes.

Tie `dismissible` to your own state so it only blocks dismissal while it matters. Disable your own cancel button for the same period:

```tsx demo
import { useState } from "react";

import { Button } from "@tenstorrent/vesper/button";
import { Modal } from "@tenstorrent/vesper/modal";
import { TextInput } from "@tenstorrent/vesper/text-input";

export default function NonDismissibleModal() {
  const [isOpen, setIsOpen] = useState(false);
  const [isSubmitting, setIsSubmitting] = useState(false);

  return (
    <>
      <Button onClick={() => setIsOpen(true)}>Invite teammate</Button>
      <Modal
        open={isOpen}
        onOpenChange={setIsOpen}
        title="Invite teammate"
        description="Send an email invitation to join your workspace."
        dismissible={!isSubmitting}
      >
        <form
          style={{
            display: "flex",
            flexDirection: "column",
            gap: "var(--vesper-spacing-6)",
          }}
          onSubmit={async (event) => {
            event.preventDefault();
            setIsSubmitting(true);
            // simulate a slow network request
            await new Promise((resolve) => setTimeout(resolve, 3000));
            setIsSubmitting(false);
            setIsOpen(false);
          }}
        >
          <TextInput
            required
            type="email"
            aria-label="Email address"
            placeholder="Email address"
            name="email"
          />
          <div
            style={{
              display: "flex",
              justifyContent: "flex-end",
              gap: "var(--vesper-spacing-4)",
            }}
          >
            <Button
              variant="tertiary"
              type="button"
              onClick={() => setIsOpen(false)}
              disabled={isSubmitting}
            >
              Cancel
            </Button>
            <Button type="submit" disabled={isSubmitting}>
              {isSubmitting ? "Sending…" : "Send invite"}
            </Button>
          </div>
        </form>
      </Modal>
    </>
  );
}
```
